\section{Reproducibility Commands}
\label{app:reproducibility-commands}

This appendix records the commands used to rebuild the current paper assets
from existing artifacts.  The commands are local paper-asset commands only:
they do not submit Slurm jobs, do not run generation, do not run model scoring,
and do not train models.

\subsection{Figure Rendering}

\begingroup\footnotesize
\begin{verbatim}
python3 scripts/verification_substrate_gap/render_vsg_manuscript_figures.py
\end{verbatim}
\endgroup

The renderer reads:

\begingroup\footnotesize
\begin{verbatim}
results/verification_substrate_gap/paper_figure_data_20260530/
\end{verbatim}
\endgroup

and writes PNG figures to:

\begingroup\footnotesize
\begin{verbatim}
manuscripts/69db2644566dcc36c9da320e/figures/
results/verification_substrate_gap/paper_manuscript_figures_20260531/
\end{verbatim}
\endgroup

\subsection{Attack Example Review}

\begingroup\footnotesize
\begin{verbatim}
python3 scripts/verification_substrate_gap/build_vsg_attack_examples_review.py
\end{verbatim}
\endgroup

The script reads existing guided rewrite/graft examples and writes a compact
review table under:

\begingroup\footnotesize
\begin{verbatim}
results/verification_substrate_gap/paper_attack_examples_20260531/
\end{verbatim}
\endgroup

The output rows remain source-mismatch examples.  They are report-only
spoofing evidence and are not protected success or codeword recovery.
